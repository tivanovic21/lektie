# Lektie Studio (web)

Backoffice for admins, teachers and editors: edit book content (chapters, quizzes, explanations, chapter links) and see student progress.

React + TypeScript + Vite. Talks to the Web API (`http://localhost:8082`).

```bash
pnpm install          # from the repo root
pnpm web              # dev server on http://localhost:5173
pnpm --filter @lektie/web build
```
